## 1. 主要任务

| 项 | 内容 |
|---|---|
| 主要任务 | 查看、测量、编辑一个晶体结构，然后导出给下游计算 |
| 操作对象 | 项目中的一个结构文档 |
| 必须随时可用的动作 | 旋转和缩放视图、选中原子、测量、编辑位点和晶胞、导出 |
| 做决定需要的信息 | 晶胞参数、空间群与编辑模式、位点列表（Wyckoff、多重度、占位率）、选中原子的约束、诊断 |
| 需要设计的状态 | 未打开结构、导入中、导入有诊断、解析失败（带行号）、对称模式与 P1 模式 |

## 2. 窗口外壳

参考 Claude Desktop、Codex 这类应用的结构（不复制它们的视觉）：左侧项目列表，中间主工作区，右侧可切换面板。

```text
┌──────────────┬──────────────────────────────────────────────┐
│ 窗口按钮  ⇤  │ ╭ 顶栏：位置 · 模式标签 · 已保存 · 导出… · ⊟ ╮│
│ 新建项目     │ │                                 │ 面板标签 ││
│ 打开项目…⇧⌘O │ │                                 │──────────││
│ 打开文件… ⌘O │ │                                 │          ││
│ 搜索命令 ⌘K  │ │            3D 视口              │ 属性      ││
│              │ │                                 │ 位点      ││
│ 项目         │ │                                 │ 测量      ││
│ ▾ TiO₂ 相研究│ │      ╭ 浮动视图工具条 ╮         │ 诊断      ││
│    金红石    │ │      ╰────────────────╯         │          ││
│    …         │ ╰─────────────────────────────────┴──────────╯│
│ 设置…        │                                               │
└──────────────┴──────────────────────────────────────────────┘
```

- **左侧边栏直接放在窗口背景上**，不画边框；红黄绿窗口按钮放在边栏顶部，不单独占一条标题栏。
- **主工作区是一张圆角卡片**（外圆角用主题的大圆角档），嵌在窗口背景上，四周留出间距。卡片内部再分为视口和右侧面板。
- **尺寸约束**：

  | 区域 | 最小 | 默认 | 最大 | 多余空间 |
  |---|---|---|---|---|
  | 左侧边栏 | 200 px | 260 px | 360 px | 不吸收 |
  | 视口 | 480 px | — | — | 吸收全部 |
  | 右侧面板 | 280 px | 340 px | 520 px | 不吸收 |

  这三个数是按当前 `rem` 换算后的目标值，实现时用 rem 辅助函数表达，不写死像素。边栏和面板的宽度可以拖动调整，并随项目持久化；恢复时按当前窗口宽度收敛。
- **窗口变窄时的顺序**：先收起右侧面板，再收起左侧边栏，视口始终保留。收起的区域都可以通过顶栏按钮或快捷键重新打开。

## 3. 左侧边栏

- 顶部四个全局动作：`新建项目`、`打开项目…`（⇧⌘O）、`打开文件…`（⌘O）、`搜索命令`（⌘K）。`新建项目`立即在列表里加一个空的"未命名项目"，不弹对话框，所以不带省略号；第一次保存时再选位置（[项目文件设计稿](project-format.md)第 9 节）。
- **项目列表**：列出这次打开着的项目，启动时恢复上次退出时打开的（第一次启动打开随应用附带的示例项目）。每个项目可以展开，列出其中的结构；派生结构（如超胞）在名称后标"派生"；有未保存更改的结构（编辑过，或导入、派生后还没保存）在行尾加一个圆点，悬停提示"有未保存的更改"。折叠的项目在行尾显示结构数量（尚未实现）。
- **项目的右键菜单**：`保存`、`另存为…`、`在访达中显示`（未保存过的项目置灰）、`关闭项目`。命令面板里有同样的命令，作用于当前项目。
- **打开文件**加入当前项目（当前结构所在的项目，或刚新建、刚打开的项目）；没有打开的项目时新建一个未命名项目。拖进窗口的 `.mwproj` 文件夹按项目打开，其他文件导入。
- **能打开的文件按文件名认格式**（M10）：`.cif` 是 CIF；`.vasp`、`.poscar` 和以 POSCAR、CONTCAR 开头的文件名（`POSCAR`、`CONTCAR`、`POSCAR-001`、`CONTCAR.relax`）是 POSCAR。系统的打开面板不按类型过滤，认不出的文件给错误通知，列出支持的格式。结构名取文件名去掉扩展名；文件名就是 POSCAR 或 CONTCAR 时（每次 VASP 计算都这样命名）前面加上所在文件夹，如"Si-relax · CONTCAR"，否则同一项目里会有一串同名的结构。
- **选中态用整行填充色表示**，不使用左侧竖条或单边边框。
- 底部是 `设置…`。
- 边栏可以整体收起（⌘\）。

## 4. 主工作区

### 4.1 顶栏

从左到右：

1. **位置**：`项目 / 结构`。项目名是按钮，点击回到项目。
2. **模式标签**：`对称模式 · P4₂/mnm` 或 `P1 模式`，常驻显示，因为它决定了编辑的作用范围。
3. **保存状态**：`已保存` / `有未保存的更改`，说的是当前结构**所在项目**的状态，因为 ⌘S 保存的是整个项目（M6）：项目里任何一个结构有编辑、有导入或派生后还没保存的结构、项目从没保存过，都显示后者。撤销回保存时的状态，又变回`已保存`。保存成功不另发通知，状态本身就是反馈。
4. **撤销 / 重做**：两个图标按钮，提示里写明要撤销或重做的命令（如"撤销「删除位点」"）和快捷键；没有可撤销的命令时禁用。
5. **`导出…`** 按钮。
6. **侧面板开关**，按下状态与面板是否显示一致。

### 4.2 视口

视口占满工作区剩余空间。它上面的元素全部由 GPUI 绘制在 3D 画面之上（见视口技术文档 5.5 节）：

| 元素 | 位置 | 内容 |
|---|---|---|
| 信息标签 | 左上 | 显示范围（如 `1 × 1 × 1 晶胞`）、原子数、投影方式 |
| 浮动视图工具条 | 底部居中 | 显示模型（球棍 / 空间填充 / 多面体）、测量开关、`显示范围…`、重置视图 |
| 测量标注 | 跟随测量对象 | 键长、键角数值 |
| 坐标轴 | 左下 | a、b、c 三轴，颜色之外同时标字母 |

**交互**：

- 鼠标：拖动旋转，滚轮缩放，按住修饰键拖动平移，单击选中原子，⇧ 单击加选。
  - 移动不超过 4 像素的按下 – 松开算单击，超过就是拖动旋转。
  - 单击选中的是这一个原子（`AtomRef`，包括它的晶胞偏移），不是整个位点；在位点列表里点选才是整个位点（它的全部等效原子都标记）。属性面板显示最后选中的那个原子所在的位点。
  - ⇧ 单击或 ⌘ 单击把原子加入选区，再点一次移出。单击空白处清空选区；点在键上不改变选区。
  - 选中的原子在轮廓外画一圈强调色的环，鼠标悬停的原子画一圈浅色的环，并在旁边显示位点标签和这个原子的分数坐标。
- 键盘：视口可以获得焦点；方向键旋转，`+` / `-` 缩放，⌘0 重置视图，Esc 清除选择。（M3 实现了 Esc 和 ⌘0。）
- 测量模式下依次点选 2 个原子得到距离、3 个得到键角；结果进入右侧"测量"标签页。具体规则：
  - 前两个原子给出它们的距离；接着点第 3 个，得到以第 2 个原子为顶点的键角，然后重新开始。只要距离时，点空白处或按 Esc 重新开始。
  - 已点的原子画选中环（测量模式下视口标记的是这些原子，而不是选区）；视口顶部居中提示下一步该点什么。
  - 每个测量在视口里画成一条虚线，并带一个数值标签：距离在两原子中点上方，键角在顶点处、两臂之间。
  - 已有的同一个测量不重复添加；关闭测量模式时丢弃未完成的那一组。

### 4.3 右侧面板

用标签切换，一次只显示一个：

| 标签 | 内容 |
|---|---|
| 属性 | 晶胞参数（受对称性约束的字段显示链接或锁图标；晶格保持文件给的基矢方向时，体积下面一行弱化文字说明"晶胞轴保持给定的方向，不是 a 沿 x 轴的标准朝向"，左手系时说明"a、b、c 构成左手系"，见[晶体学设计稿](crystallography-model.md) 4.2 节）、对称性（空间群、编辑模式、`转为 P1…`）、选中位点（Wyckoff、坐标形式、按约束联动的坐标；每个占位者一行：标签（可改名）、元素选择器、占位率、混合占位时的删除按钮；`添加混合占位…`） |
| 位点 | 不对称单元的位点列表，每项两行：标签、元素、Wyckoff、等效原子数 / 坐标、占位率；`添加位点…` |
| 测量 | 已有测量的列表：标签（如 `O1–Ti1–O1`）、数值、删除按钮；引用失效的测量标为"已失效"。下方说明测量的点选方式 |
| 诊断 | 导入和编辑产生的诊断，标签上显示数量 |

位点列表和视口的选择是同一个选区：在一边选中，另一边同步高亮。

**属性面板里的编辑**（M4）：

- 数值字段按回车或离开字段时提交，结果与原值相同时什么都不做；不是数字或被拒绝（如晶胞无法成立、占位率超出 (0, 1]）时，通知说明原因，字段恢复原值。
- 元素选择器是可搜索的下拉列表，选中即替换，作用于整个位点。
- 标签字段同样按回车或离开字段时改名（`RenameLabel`，可以撤销），首尾空格去掉。标签为空、含空格、以 CIF 保留的字符开头，或已被别的占位者使用时，通知说明原因，字段恢复原值。改名后字段保留焦点，位点标题、位点列表和视口的悬停提示跟着改名。
- 编辑带来的警告（占位率之和大于 1、原子过近）用警告通知提示，不弹对话框。
- 对称模式下的坐标字段：自由坐标仍可输入，但移动位点属于 v0.2，提交时提示尚未实现；P1 模式下三个坐标都可以直接修改。

### 4.4 空状态

没有打开结构时：标题"打开一个结构"、说明、`打开文件…` 和 `打开示例项目`，下面是最多 5 个最近的项目（名称和路径），点击打开。

## 5. 弹出层

按"最小够用"的原则选择：

| 场景 | 弹出层 |
|---|---|
| 搜索并执行命令 | 命令面板（⌘K）。中文、英文、拼音都能匹配，结果按"结构 / 视图 / …"分组 |
| 删除整个位点（位点列表里选中，或选中了它的全部等效原子；P1 下的任何原子） | 不确认，直接删除并发通知写明范围（如"已删除 O1（3 个原子）"）；删除可以撤销 |
| 对称模式下删除单个原子 | 对话框，给出 `取消` / `删除全部 N 个` / `转为 P1 后删除这一个`，默认动作是最后一个：转为 P1 和删除是一步，撤销一次回到对称结构，通知写明删除了几个原子 |
| 添加混合占位 | 对话框：元素选择器和占位率，`取消` / `添加` |
| 导入完成但有诊断 | 通知，加上诊断标签页的数量提示；不弹模态框 |
| 转为 P1、生成超胞等需要参数或确认的操作 | 对话框，按钮和菜单项带省略号。转为 P1 在原结构上执行、可以撤销，选区和测量跟着原子走；生成超胞的对话框填 a、b、c 三个方向的倍数并实时写出原子数，结果作为派生结构加进项目并打开 |
| 导出 | 对话框选格式，再用系统保存面板选文件（见下） |
| 导出完成或失败 | 通知；完成时带"在访达中显示" |
| 关闭项目或退出时有未保存的更改 | 对话框：标题"关闭前保存对「名称」的更改吗？"（退出时"退出前保存……"，几个项目时写数量并在正文列出名称），正文"不保存的话，这些更改会丢失。"，按钮 `取消` / `不保存` / `保存`（默认）。保存未命名项目时先弹系统保存面板，取消或保存失败就停在原处 |
| 保存失败、另存为的位置已被占用 | 错误通知，写明原因；已有的项目和文件夹不会被覆盖 |
| 打开项目失败（不是项目、版本更新、文件损坏） | 错误通知，写明原因和文件；读不了的单个结构只在点开它时报告，不影响项目里其他结构 |

**导出对话框**：标题是"导出“结构名”"，正文是三个单选项：CIF、POSCAR（VASP 5）、扩展 XYZ，每项下面一行弱化文字说明写出什么（"保留对称操作、位点、占位率和 ADP"、"展开为 P1，分数坐标"……）。结构装不进的格式置灰，说明换成原因，例如"部分占位（Ti1），需要先有序化"。按钮和删除对话框一样右对齐：`取消` 和 `导出…`（默认动作，回车触发，打开系统保存面板，所以带省略号）。默认选中本次会话上次用的格式；系统保存面板打开在上次导出的目录，建议的文件名是结构名加 `.cif` / `.vasp` / `.xyz`。成功不另弹对话框，只发通知，因为写好的文件在界面里看不到。

所有弹出层都能盖在视口上（这是选择回读方案的原因之一），Esc 关闭最上层并把焦点还给触发者。

**设置**：深色模式和界面语言改了就保存，下次启动时沿用（[项目文件设计稿](project-format.md)第 10 节）。

## 6. 视觉语言

- **颜色只用语义角色**：窗口背景、卡片表面、边框、弱化文字、选中填充、强调色（蓝色，只用于选中和焦点）。深色主题同样适用。
- **数据颜色例外**：元素颜色沿用 Jmol 配色，坐标轴 a / b / c 用橙红 / 绿 / 蓝；它们是数据本身的颜色，不进主题。
- **密度**：面板和工具条用紧凑尺寸（控件约 28 px 高），其余用默认尺寸。
- **字体**：界面用系统字体；数值、坐标、键长用等宽字体并右对齐。
- **受约束的字段**：联动字段显示链接图标和"= a"之类的说明，固定字段显示锁图标；两者都是只读外观，但文字仍保持可读的对比度。
- **阴影只给浮在上层的东西**：浮动视图工具条、弹出层、对话框；卡片和面板只用背景色和细线区分。
