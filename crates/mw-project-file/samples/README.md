# Sample projects

The projects shipped with Materials Workbench (`docs/design/project-format.md` §11), embedded by `src/samples.rs`:

| Project | Content |
|---|---|
| `tio2.mwproj` | 金红石 (rutile), imported from `rutile.cif`, and a 2 × 2 × 2 supercell derived from it |
| `perovskite.mwproj` | SrTiO₃, imported from `SrTiO3.cif` |

The copies under `sources/` are the hand-written test fixtures of `crates/mw-crystal-io/tests/fixtures/` (commonly cited literature parameters, nothing copied from a database). Everything here is generated by `tests/samples.rs`; do not edit it by hand. After changing the project format or those fixtures, regenerate:

```bash
cargo test -p mw-project-file --test samples -- --ignored
```
